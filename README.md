# Bearshare

단국대학교 천안캠퍼스 유휴 공간을 지역주민과 학생이 함께 쓰는 공간 공유 웹앱의 **MVP 화면 시제품**입니다.
캡스톤디자인2(공공정책) 쥬라기월드조.

## 화면

| 파일 | 화면 |
| --- | --- |
| `index.html` | 홈 |
| `spaces.html` | 공간안내 |
| `guide.html` | 대관안내 (절차·이용 기준·주의사항) |
| `reserve.html` | 대관신청 (공간별 시간표, 30분 단위 선택) |
| `classes.html` | 수업 둘러보기 (학생 제안 → 관리자 승인 → 원데이클래스) |
| `login.html` | 로그인 (지역주민 / 재학생) |
| `mypage.html` | 내 예약 내역 |

## 보는 법

- 웹: GitHub Pages 주소로 접속
- 내 컴퓨터: `Code → Download ZIP` → 압축 풀기 → `index.html` 더블클릭

## 알아 둘 점

- 데이터는 모두 예시이며, 신청해도 실제로 저장·접수되지 않습니다.
- 강당·운동장·체육관·강의실 정보는 가상입니다.
- 운영 시간(가정): 평일 베어토피아 09–22시·그 외 19–22시 / 주말 체육관·운동장 18–22시·그 외 09–22시.
